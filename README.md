# RWA - Multimedijska Web Aplikacija

Baza podataka za multimedijsku aplikaciju sa korisničkim ulogama i TMDB integracijom.

## 📁 Datoteke

- **`database_schema.sql`** - SQL schema za import u MySQL Workbench
- **`UPUTE.md`** - 🇭🇷 **Jednostavne upute na hrvatskom jeziku** (POČNI OVDJE!)
- **`BAZA_PODATAKA.md`** - 🇭🇷 Detaljan opis baze podataka na hrvatskom
- **`DATABASE_README.md`** - 🇬🇧 English documentation
- **`ER_DIAGRAM_GUIDE.md`** - 🇬🇧 Technical guide in English

## 🚀 Brzi start

1. **Preuzmi** `database_schema.sql` datoteku
2. **Otvori** MySQL Workbench
3. **Importaj:** File → Import → Reverse Engineer MySQL Create Script
4. **Gotovo!** ER dijagram je kreiran

👉 **Detaljne upute:** Pogledaj **[UPUTE.md](UPUTE.md)**

## 📊 Što sadrži baza?

- ✅ 10 tablica sa vezama
- ✅ 4 razine korisničkih uloga (Admin → Moderator → Korisnik → Gost)
- ✅ TMDB integracija
- ✅ Straničenje na serveru
- ✅ Ocjenjivanje i recenzije
- ✅ Omiljeni sadržaj
